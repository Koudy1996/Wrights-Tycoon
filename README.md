# Wright Tycoon 0.5

Unity tycoon/simulation prototype focused on designing aircraft (engine + airframe/type), running monthly production, and fulfilling contracts.

## Play (prebuilt)

- Windows build: `Builds/Windows/Release/WrightTycoon.exe`
- macOS build: `Builds/Mac/Release/WrightTycoon.app` (or the archive `Builds/Mac/WrightTycoon-macOS-Release.tar.gz`)

Runtime data (saves/logs/etc.) is written into a `Player Info/` folder next to the executable (see [Docs/Documentation.md](Docs/Documentation.md)).

## Develop

Open the project in Unity Hub using the version from `ProjectSettings/ProjectVersion.txt` (Unity `6000.3.9f1`).

For editor play and builds, use the Unity menu workflow described in [Docs/Documentation.md](Docs/Documentation.md).
