# Single-engine aircraft shape references

The preview generator uses project-authored low-poly station profiles. No source mesh, texture,
UV layout or animation data from the references below is copied into the project.

## Piston fuselage family

- **Spitfire Mk IXe** by martinsifrar
  - Source: https://sketchfab.com/3d-models/spitfire-mk-ixe-4bfb316cfc65457e9bc97346b3ccf591
  - License listed by Sketchfab: CC Attribution 4.0
  - Used as a silhouette reference for the long engine cowling, spinner transition, cockpit
    placement and tapered rear fuselage.
- **Spitfire Mk.I outline study**
  - Source: https://soyuyo.main.jp/spit1a/spit1ae.html
  - Used to check the relationship between the upper cowling, windscreen, canopy rail and fuselage
    reference line.

## Central jet fuselage family

- **F86** by manilov.ap
  - Source: https://sketchfab.com/3d-models/f86-e1cd8975123a47599423e4da19a8910b
  - License listed by Sketchfab: CC Attribution 4.0
  - Used as a silhouette reference for the circular nose intake, barrel-shaped center fuselage,
    bubble canopy and integrated tailpipe.
- **F-86 Saber aircraft illustration, USAF Supplement No. 2 (June 1951)**
  - Source: https://manuals.plus/m/de74e063a617f2ce932a6a273057a6111785c92b1ac94869749f7220fb553603.pdf
  - Used to cross-check the nose-intake-to-fuselage and fuselage-to-tailpipe transitions.

The rest of the aircraft preview remains driven by Wright Tycoon's existing modular wing, tail and
landing-gear generators.
